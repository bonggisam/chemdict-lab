# ChemDict Lab 디자인 기준

화면을 새로 만들거나 고칠 때 이 문서를 따릅니다. 웹앱(`web/src/styles.css`)과 애플 앱(비공개 저장소 `ChemDictLab/Theme.swift`)은 같은 값을 씁니다.

## 1. 누구를 위한 화면인가

- **쓰는 사람:** 실험대 앞의 고등학생(아이패드 1인 1대, 장갑·젖은 손일 때도 있음), 맥북으로 수업을 진행하는 교사
- **화면의 주된 일:** 센서 값을 **읽고**, 기록하고, 그래프로 **해석**하기
- **환경:** 밝은 실험실, 프로젝터, 다크 모드 아이패드

## 2. 방향

1. **측정값이 주인공.** 화면에서 가장 큰 것은 지금 측정값(계기판 숫자)입니다. 나머지는 조용하게 둡니다.
2. **채널 로고에서 온 색 (v0.7).** 유튜브 채널 '화학사전' 로고의 숲빛 검정(`#0f1a17`)·민트 육각형(`#00d49a`)·주황 원자(`#ff7a3d`)를 씁니다. 글자·버튼 강조는 대비를 지킨 진한 민트(`#007a5e`), 주황은 '지금'(현재 단계, 측정 시작, 측정 중 점)에만 씁니다. 측정 데이터 색(파랑·주황…)은 그대로입니다.
2-0. **화면 디자인(2.1):** 기본은 민트(밝게). 사용자가 디자인 10가지(밝은 6 · 어두운 4)나 '기기 설정 따르기'를 고를 수 있음 — 아래 "3-1. 화면 디자인". 2.0에서 저장한 값(`light`·`dark`·`system`)은 그대로 통한다.
2-0. **2.0 A안 '밝고 깔끔한 교과서풍'.** 밝은 화면에서는 목차·위쪽 띠도 흰색으로 두고(구분선 `#e3e7e5`), 숲빛 검정은 어두운 화면에서만 씁니다. 교실 프로젝터에서 잘 보이도록 바탕은 거의 흰색(`#f7f8f7`), 민트는 강조에만.
2-1. **대담함은 한 곳.** 위쪽 띠(숲빛 검정, 로고, 분자 사슬 모양 단계 표시: 단계=원자, 사이=점선 결합, 지금 단계=주황 원자)만 눈에 띄게 하고 본문은 조용하게 둡니다.
2-2. **이모지 아이콘.** 센서 분류·버튼 앞에 이모지를 붙여 한눈에 찾게 합니다 (`web/src/lib/icons.ts`, 애플 `Theme.categoryIcon`). 번역 문구에는 넣지 않고 따로 붙이며 화면 읽기에서는 건너뜁니다(`aria-hidden`).
3. **실험 순서대로.** 화면 배치는 연결 → 고르기 → 측정 → 해석 → 내보내기 순서입니다. 번호는 실제로 순서가 있는 곳(연결 안내, 실험 순서)에만 씁니다.
4. **꾸밈은 과학에서 가져온 것만 (2.1 '사이버 실험실').** 화면이 투박하다는 의견에 따라 계기판 느낌의 꾸밈을 더했습니다. 쓰는 모양은 아래 다섯 가지뿐이고, 모두 화면 디자인 토큰(`--glow-rgb`·`--mid-rgb`·`--accent`)을 따라가 10가지 디자인에서 함께 바뀝니다 (웹 styles.css 맨 끝 "2.1 '사이버 실험실' 꾸밈", 애플 `LabStyle.swift`).
   - **모눈 바탕:** 실험 노트의 모눈처럼 22px 간격의 옅은 점 + 오른쪽 위의 은은한 빛.
   - **육각형(벤젠 고리 = 로고):** 단계 번호, 목차의 단계, 센서 카드 아이콘, 첫 화면 큰 버튼의 아이콘 판.
   - **계기 틀:** 그래프 칸 네 모서리의 꺾쇠와 계기판 숫자 칸. 대담함은 여기 한 곳 — 측정 화면에서는 제목 뒤 장식을 빼서 측정값이 주인공이 되게 합니다.
   - **제목 뒤 장식:** 벌집 격자 + 적정 곡선(가림막 그림이라 디자인 색을 따라감). 측정 화면에는 없음, 좁은 화면에서는 더 옅게.
   - **빛나는 가장자리:** 카드 위쪽 신호선, 누를 수 있는 것에 올렸을 때의 빛, 목차 오른쪽 빛줄, 어두운 디자인의 계기판 숫자 빛.
   - 저절로 움직이는 것은 **로고 둘레를 도는 전자 하나**와 '측정 중' 주황 점뿐이고, 움직임 줄이기 설정이면 멈춥니다. 꾸밈 때문에 글자 대비·44px 터치·측정 색을 바꾸지 않습니다.
   - **이모지:** 목차의 단계·가지, 이모지가 없던 제목, 화면 바꾸기 버튼에도 붙였습니다 (제목은 `<Ico e="…" />`, 목차 가지는 `data-nav-ico`. 번역 문구에는 넣지 않음).

### 3-1. 화면 디자인 10가지 (2.1)

위 표는 기본 디자인(밝은 화면 = 민트, 어두운 화면 = 숲)의 값입니다. 사용자는 아래 10가지 가운데 하나나 '기기 설정 따르기'(기기가 밝으면 민트, 어두우면 숲)를 고릅니다.

| id | 이름 | 화면 | 바탕 `--bg` | 카드 `--surface` | 강조 `--accent` | 빛 `--mint` |
|---|---|---|---|---|---|---|
| `light` | 민트 | 밝은 | `#f7f8f7` | `#ffffff` | `#007a5e` | `#00d49a` |
| `ocean` | 바다 | 밝은 | `#f4f8fb` | `#ffffff` | `#0a67a3` | `#38b2f5` |
| `lavender` | 라벤더 | 밝은 | `#f8f6fc` | `#ffffff` | `#6941c6` | `#a78bfa` |
| `blossom` | 벚꽃 | 밝은 | `#fcf6f8` | `#ffffff` | `#b0306a` | `#f472b6` |
| `paper` | 종이 | 밝은 | `#f6f1e7` | `#fffdf8` | `#7a4b12` | `#d9a04a` |
| `mono` | 흑백 | 밝은 | `#f5f5f6` | `#ffffff` | `#2f3542` | `#8b93a7` |
| `dark` | 숲 | 어두운 | `#0b1411` | `#13211c` | `#2ee6b0` | `#00d49a` |
| `board` | 칠판 | 어두운 | `#16291f` | `#1d3528` | `#ffd866` | `#ffd866` |
| `navy` | 밤바다 | 어두운 | `#0b1220` | `#131d31` | `#6cb6ff` | `#4aa3ff` |
| `contrast` | 고대비 | 어두운 | `#000000` | `#101010` | `#ffd60a` | `#ffd60a` |

- **색은 `tools/make_themes.py` 한 곳에서만 고칩니다.** 실행하면 `protocol/themes.json`과 `web/src/styles.css`의 `THEMES` 구간이 함께 만들어지고, 애플 앱은 `tools/make_palettes.py`가 같은 json으로 `Palettes.swift`를 만듭니다. 두 파일은 직접 고치지 않습니다.
- 스크립트가 디자인마다 대비를 검사하고, 하나라도 모자라면 파일을 쓰지 않습니다: 본문 7:1, 보조 글자·강조·버튼 글자·목차 글자·배지 4.5:1, 입력칸 테두리 3:1, 어두운 디자인의 측정 색 3:1.
- 디자인이 바꾸는 것은 바탕·카드·글자·구분선·강조·목차 색뿐입니다. **측정(run) 색, 주의(`--mark`)·위험·확인 색, 주황 원자(`--atom`)는 바꾸지 않습니다** (밝은 화면용 / 어두운 화면용 두 벌). 그래프의 뜻이 디자인에 따라 달라지면 안 됩니다.
- 웹: `<html data-theme="디자인 id" data-scheme="light|dark">` (`lib/theme.ts`, 첫 칠은 `index.html`의 한 줄 스크립트). **어두운 화면에만 쓰는 규칙은 `:root[data-scheme="dark"]` 선택자에 넣습니다** (`prefers-color-scheme` 미디어 쿼리를 쓰지 않음). 민트 계열 반투명 색은 `rgba(var(--glow-rgb), …)`·`rgba(var(--mid-rgb), …)`로 써서 디자인을 따라가게 합니다.
- 애플: `Design`(`chemdict.theme`) → `Theme.paper`·`card`·`accent`… 가 고른 팔레트를 돌려줌. 디자인이 바뀌면 `RootView`가 `.id(design)`으로 화면을 다시 그립니다.
- 새 디자인을 더할 때: `make_themes.py`의 `LIGHT`/`DARK`에 한 줄 → 실행 → 이름을 `lib/theme.ts`의 `tk(…)`에 추가 → 번역 → 어두운 디자인이면 `index.html`의 목록에도 추가 (`tests/theme.test.ts`가 확인) → `node e2e/themes.cjs`.

## 4. 글자

- 글꼴: **Pretendard Variable** 하나 (웹은 jsDelivr CDN, 애플 앱은 시스템 글꼴)
- 숫자는 항상 `tabular-nums` (자릿수 정렬)

| 단계 | 크기 | 쓰는 곳 |
|---|---|---|
| 측정값 | 34px, 700 | 그래프 오른쪽 위 지금 값 |
| 제목 | 24~32px, 700 | 화면 제목 |
| 소제목 | 19px, 700 | 카드 제목 |
| 본문 | 16px | 설명, 목록 |
| 보조 | 13~15px | 메모, 축 이름, 범례 (13px 아래로 내리지 않음) |

- 측정값 숫자는 **글자색(`--ink`)**으로 씁니다. 측정 색으로 칠하지 않습니다 (색은 옆의 선·점이 맡음).
- 모든 글자를 대문자로 쓰거나, 제목의 한 단어만 다른 색으로 칠하지 않습니다.

### 핵심어 색 (v0.8, `components/Rich.tsx` · 애플 `Theme.swift`의 `Rich`·`TreeList`)
안내 문장(연결 순서, 규칙, 주의, 실험 순서)의 중요한 낱말만 자동으로 칠합니다. 제목에는 쓰지 않습니다.

| 종류 | 예 | 색 |
|---|---|---|
| 누를 버튼 `[ … ]` | [측정 시작] | 진한 민트 `--accent` + 옅은 바탕 |
| 핀·단자 | 5V, GND, A0, D2, SDA | 파랑 `--pin` (#1d5fb0 / 어두운 화면 #8cbcff), 고정폭 글꼴 |
| 주의 낱말 | 주의, 금지, 합선, 화상 | 주황 `--mark`, 굵게 (주의 상자 안에서는 밑줄도) |
| 숫자+단위 | 30초, 4.7 kΩ, 25 °C | 글자색 굵게 |

낱말은 그대로 남아 있어 색을 못 봐도 뜻이 같습니다.

### 화면 틀 (v0.8): 왼쪽 목차 + 오른쪽 내용
- 왼쪽(280px, 숲빛 검정): 단계 1·2·3이 줄기, 지금 화면의 소제목이 가지. 가지는 본문의 `h2`와 `data-nav="이름"`을 읽어 저절로 만들어지고, 누르면 그 자리로 갑니다. 지금 보이는 곳은 민트 막대로 표시합니다.
- 실험을 고르면 2단계 아래에 "📈 실험 이름" 가지가 생기고, 그 아래에 측정 화면의 칸(측정 시작·측정 목록·그래프·저장·해석)이 붙습니다. 측정 중에는 🔴, 다른 단계는 잠깁니다.
- 900px보다 좁으면 왼쪽 목차는 위쪽 띠의 [☰ 지금 단계] 버튼 안에 접힙니다.
- 본문의 목록(연결 순서·규칙·문제 해결·주의)은 세로줄과 꺾은 선으로 이은 나무 모양으로, 순서 목록은 번호 원을 붙입니다.

## 5. 크기와 간격

- 누르는 것은 모두 **44×44px 이상** (`--target`). 장갑을 낀 손가락 기준입니다.
- 모서리: 카드 10px, 작은 요소 6px, 알약 모양 칩 999px
- 그림자 없음. 카드 구분은 `--line` 테두리 1px

## 6. 그래프 규칙 (dataviz 스킬)

1. **그래프 하나에 세로축 하나.** 기온과 습도는 그래프 두 개로 나눕니다.
2. 선 2px, 점 지름 9px 이상, 겹치는 점에는 바탕색 2px 테두리
3. 격자는 실선 1px, `--line`. 점선은 의미가 있을 때만 씁니다 (예측선, 직선 맞춤, 관찰 기록).
4. 범례: 측정이 2개 이상일 때 항상 표시. 숫자를 모든 점에 붙이지 않습니다.
5. 마우스·손가락을 대면 가장 가까운 점의 값을 보여 줍니다.
6. 상태(안정·변하는 중, 인식됨)는 **기호 + 글자**로 표시합니다. 색만으로 구분하지 않습니다.
7. 모든 그래프에는 **표 보기**와 **CSV 내보내기**가 있습니다.
8. **축 이름과 단위**를 항상 씁니다 (v0.9): 세로축은 왼쪽 위에 `이름 (단위)`, 가로축은 시간 단위(`초 (s)`·`분 (min)`·`분:초`·`시각`) 또는 값 입력 모드의 입력값·단위. 사용자가 고른 격자(가로·세로/가로만/촘촘하게/없음)와 시간 표기는 저장되어 다음 측정에도 유지됩니다 (웹 `chemdict.chartView`, 애플 `chemdict.chartGrid/chartTime/chartYLabel`).
9. 센서별 해석 안내(`protocol/analysis_methods.json`)는 해석 도구 위에 접힌 상태로 두고, [적용]을 누르면 그 도구가 바로 켜집니다. 안내는 도구를 늘리지 않고 **있는 도구를 고르는 길잡이**입니다.

### 참고 자료 칸 (v0.9)

- **시약·약품** (`protocol/reagents.json`): 실험 준비물에서 시약을 찾아 칩(⚠는 GHS 위험 있음)으로 보여 주고, 누르면 위험·보호구·조제 방법·다룰 때·보관·폐기·응급 처치 카드가 열립니다. 교사용 정보이므로 측정 흐름(센서 카드 → 연결 그림 → 측정 시작) 밖, 실험 순서 아래에 둡니다.
- **센서 점검 · 오차** (`SensorCheckSheet`, `protocol/sensor_checks.json`): 측정값을 읽는 데서 끝내지 않고 해석하게 하는 칸. 사양(범위·정확도·분해능·반응 시간) → 지금 값(최근 평균 ± 흔들림) → 기준 상황(얼음물 0 °C, pH 7 완충액, 바깥 공기 CO₂ …)을 고르면 오차(절대·상대)와 통과/벗어남 판정 → 정상 작동 테스트 체크리스트 → 고장 신호. 통과는 초록 테두리, 벗어남은 주황(`--mark`) 테두리 + [센서 보정] 안내. 해석 패널에는 '기준값과 비교'(이론값·허용 오차 입력 → 오차·센서 정확도 표시).
- **3.3 V 보드 경고**: 센서 카드 배지 '5 V 전용 · 분압 필요'/'전원 5 V 핀'(주황)과 전류 배지(≥100 mA), 연결 그림 위 경고문. 보드가 5 V면 아무것도 보이지 않는다.
- **연결 사진으로 점검하기** (`PhotoCheck`): 사진은 기기 밖으로 보내지 않습니다. 연결 표에서 만든 점검 목록(선 → 핀)을 사용자가 사진과 맞춰 보며 체크하고, 다 맞으면 [센서 다시 찾기]로 안내합니다. 자주 하는 실수는 접힌 목록으로.

## 8. 문구

- 존댓말 "-습니다 / -세요", 짧게
- 버튼은 **누르면 일어나는 일**을 동사로: "측정 시작", "값 기록", "센서 다시 찾기"
- 버튼과 결과 알림의 낱말을 맞춥니다: "센서 다시 찾기" → "센서를 다시 찾았습니다."
- 오류는 **무엇이 안 됐는지 + 어떻게 하면 되는지**: "연결이 끊어졌습니다. 케이블이나 블루투스를 확인하고 다시 연결하세요."
- 빈 화면은 다음 할 일을 알려 줍니다: "센서를 꽂은 뒤 '센서 다시 찾기'를 누르세요."
- 기술 용어보다 학생이 보는 이름: "Wire1" 대신 "Qwiic 단자", "hello" 대신 "센서 정보"

## 9. 하지 않을 것

- 축이 두 개인 그래프
- 측정 순서에 따라 색이 바뀌는 그래프
- 색만으로 상태 표시
- 13px보다 작은 글자, 44px보다 작은 버튼
- 크림색 바탕 + 갈색 강조 같은 흔한 AI풍 조합, 모든 것에 같은 그림자를 준 카드 묶음
- 장식용 번호(01/02/03)와 모든 제목 위의 작은 대문자 꼬리표
