# ChemDict Lab 디자인 기준

화면을 새로 만들거나 고칠 때 이 문서를 따릅니다. 웹앱(`web/src/styles.css`)과 애플 앱(비공개 저장소 `ChemDictLab/Theme.swift`)은 같은 값을 씁니다.

## 1. 누구를 위한 화면인가

- **쓰는 사람:** 실험대 앞의 고등학생(아이패드 1인 1대, 장갑·젖은 손일 때도 있음), 맥북으로 수업을 진행하는 교사
- **화면의 주된 일:** 센서 값을 **읽고**, 기록하고, 그래프로 **해석**하기
- **환경:** 밝은 실험실, 프로젝터, 다크 모드 아이패드

## 2. 방향

1. **측정값이 주인공.** 화면에서 가장 큰 것은 지금 측정값(계기판 숫자)입니다. 나머지는 조용하게 둡니다.
2. **채널 로고에서 온 색 (v0.7).** 유튜브 채널 '화학사전' 로고의 숲빛 검정(`#0f1a17`)·민트 육각형(`#00d49a`)·주황 원자(`#ff7a3d`)를 씁니다. 글자·버튼 강조는 대비를 지킨 진한 민트(`#007a5e`), 주황은 '지금'(현재 단계, 측정 시작, 측정 중 점)에만 씁니다. 측정 데이터 색(파랑·주황…)은 그대로입니다.
2-1. **대담함은 한 곳.** 위쪽 띠(숲빛 검정, 로고, 분자 사슬 모양 단계 표시: 단계=원자, 사이=점선 결합, 지금 단계=주황 원자)만 눈에 띄게 하고 본문은 조용하게 둡니다.
2-2. **이모지 아이콘.** 센서 분류·버튼 앞에 이모지를 붙여 한눈에 찾게 합니다 (`web/src/lib/icons.ts`, 애플 `Theme.categoryIcon`). 번역 문구에는 넣지 않고 따로 붙이며 화면 읽기에서는 건너뜁니다(`aria-hidden`).
3. **실험 순서대로.** 화면 배치는 연결 → 고르기 → 측정 → 해석 → 내보내기 순서입니다. 번호는 실제로 순서가 있는 곳(연결 안내, 실험 순서)에만 씁니다.
4. **꾸밈보다 기록.** 카드에는 옅은 그림자 하나만, 그라데이션은 위쪽 띠에만 씁니다. 저절로 움직이는 것은 '측정 중' 주황 점 하나뿐이고, 움직임 줄이기 설정이면 멈춥니다.

## 3. 색 토큰

| 토큰 | 밝은 화면 | 어두운 화면 | 쓰는 곳 |

| `--bg` | `#eef4f1` | `#0b1411` | 화면 바탕 |
| `--surface` | `#ffffff` | `#13211c` | 카드·그래프 바탕 |
| `--ink` | `#10211c` | `#e3eee9` | 본문, **측정값 숫자** |
| `--muted` | `#52665d` | `#93a89f` | 보조 글자 (대비 5.5:1 이상) |
| `--line` | `#d3dfda` | `#24362f` | 구분선 (장식용) |
| `--field` | `#7a8d85` | `#5f7770` | 입력칸·선택칸 테두리 (3:1 이상) |
| `--accent` | `#007a5e` | `#2ee6b0` | 주요 버튼, 선택 상태, 링크 (흰 바탕 5.3:1) |
| `--mark` | `#c2410c` | `#ff8a52` | 관찰 기록 선, 주의 상자 |

### 측정(run) 색 — 그래프 전용

| 순서 | 밝은 화면 | 어두운 화면 |
|---|---|---|
| 1 | `#2a78d6` 파랑 | `#3987e5` |
| 2 | `#eb6834` 주황 | `#d95926` |
| 3 | `#1baf7a` 청록 | `#199e70` |
| 4 | `#eda100` 노랑 | `#c98500` |
| 5 | `#e87ba4` 분홍 | `#d55181` |

- dataviz 스킬의 검증 팔레트입니다. 색약 시뮬레이션(인접 ΔE 9.1 / 8.4)과 밝기 검사를 통과했습니다.
- **순서를 바꾸지 않습니다.** 측정 1은 언제나 파랑입니다. 측정을 지우거나 숨겨도 남은 측정의 색은 그대로입니다.
- 밝은 화면에서 3·4·5번은 바탕 대비가 3:1보다 낮습니다. 그래서 측정이 2개 이상이면 **범례**를 항상 보여 주고, **표 보기**를 제공합니다.
- 측정은 최대 5개입니다. 더 필요하면 새 실험 파일로 나눕니다.
- 색을 바꾸면 검증기를 다시 돌립니다: `node <dataviz 스킬>/scripts/validate_palette.js "<색,…>" --mode light --surface "#ffffff"` (어두운 화면은 `--mode dark --surface "#16212c"`)

## 4. 글자

- 글꼴: **Pretendard Variable** 하나 (웹은 jsDelivr CDN, 애플 앱은 시스템 글꼴)
- 숫자는 항상 `tabular-nums` (자릿수 정렬)

| 단계 | 크기 | 쓰는 곳 |
|---|---|---|
| 측정값 | 34px, 700 | 그래프 오른쪽 위 지금 값 |
| 제목 | 24~32px, 700 | 화면 제목 |
| 소제목 | 19px, 700 | 카드 제목 |
| 본문 | 16px | 설명, 목록 |
| 보조 | 13~15px | 메모, 축 이름, 범례 (13px 아래로 내리지 않음) |

- 측정값 숫자는 **글자색(`--ink`)**으로 씁니다. 측정 색으로 칠하지 않습니다 (색은 옆의 선·점이 맡음).
- 모든 글자를 대문자로 쓰거나, 제목의 한 단어만 다른 색으로 칠하지 않습니다.

## 5. 크기와 간격

- 누르는 것은 모두 **44×44px 이상** (`--target`). 장갑을 낀 손가락 기준입니다.
- 모서리: 카드 10px, 작은 요소 6px, 알약 모양 칩 999px
- 그림자 없음. 카드 구분은 `--line` 테두리 1px

## 6. 그래프 규칙 (dataviz 스킬)

1. **그래프 하나에 세로축 하나.** 기온과 습도는 그래프 두 개로 나눕니다.
2. 선 2px, 점 지름 9px 이상, 겹치는 점에는 바탕색 2px 테두리
3. 격자는 실선 1px, `--line`. 점선은 의미가 있을 때만 씁니다 (예측선, 직선 맞춤, 관찰 기록).
4. 범례: 측정이 2개 이상일 때 항상 표시. 숫자를 모든 점에 붙이지 않습니다.
5. 마우스·손가락을 대면 가장 가까운 점의 값을 보여 줍니다.
6. 상태(안정·변하는 중, 인식됨)는 **기호 + 글자**로 표시합니다. 색만으로 구분하지 않습니다.
7. 모든 그래프에는 **표 보기**와 **CSV 내보내기**가 있습니다.

## 7. 접근성 점검표 (WCAG 2.1 AA)

| 항목 | 기준 | 현재 |
|---|---|---|
| 본문 대비 | 4.5:1 | `--muted` 5.3:1 이상 ✓ |
| 입력칸 테두리 | 3:1 | `--field` 3.45:1 / 3.93:1 ✓ |
| 강조색 위 흰 글자 | 4.5:1 | 5.96:1 ✓ |
| 키보드 초점 | 보이게 | 강조색 2px 테두리 ✓ |
| 입력칸 이름 | 모두 | `label` 또는 `aria-label` ✓ |
| 창(시트) | Esc로 닫힘, 대화상자 표시 | ✓ |
| 움직임 줄이기 | 시스템 설정 따름 | ✓ |
| 200% 확대 | 가로 스크롤 없음 | 화면 폭 360px까지 확인 |

## 8. 문구

- 존댓말 "-습니다 / -세요", 짧게
- 버튼은 **누르면 일어나는 일**을 동사로: "측정 시작", "값 기록", "센서 다시 찾기"
- 버튼과 결과 알림의 낱말을 맞춥니다: "센서 다시 찾기" → "센서를 다시 찾았습니다."
- 오류는 **무엇이 안 됐는지 + 어떻게 하면 되는지**: "연결이 끊어졌습니다. 케이블이나 블루투스를 확인하고 다시 연결하세요."
- 빈 화면은 다음 할 일을 알려 줍니다: "센서를 꽂은 뒤 '센서 다시 찾기'를 누르세요."
- 기술 용어보다 학생이 보는 이름: "Wire1" 대신 "Qwiic 단자", "hello" 대신 "센서 정보"

## 9. 하지 않을 것

- 축이 두 개인 그래프
- 측정 순서에 따라 색이 바뀌는 그래프
- 색만으로 상태 표시
- 13px보다 작은 글자, 44px보다 작은 버튼
- 크림색 바탕 + 갈색 강조 같은 흔한 AI풍 조합, 모든 것에 같은 그림자를 준 카드 묶음
- 장식용 번호(01/02/03)와 모든 제목 위의 작은 대문자 꼬리표
