## 0. 먼저 읽기

### 0-1. 확인 표시 규칙

| 표시 | 뜻 |
|---|---|
| **확인(교육청)** | 경기도교육청 자료에서 코드와 문장을 확인함 |
| **확인(정리본)** | 성취기준 정리 문서(나무위키 과목별 문서)에 원문 인용 형태로 실린 코드와 문장. 고시 PDF와 한 글자씩 대조하지는 못함 |
| **확인(코드)·문장 요약** | 코드는 확인했고, 문장은 출처가 요약만 제공해 요약으로 적음. 원문은 고시 PDF에서 다시 봐야 함 |
| **추정** | 코드나 문장을 확인하지 못함 (이번 정리에는 없음) |
| **연계: 직접** | 성취기준 문장이나 교육과정의 '탐구 활동'·'적용 시 고려 사항'에 해당 측정이나 디지털 탐구 도구가 직접 나옴 |

- **코드 접두어 주의**: 요청에 적힌 `[12생명..]`은 실제 접두어가 아니다. 2022 개정 생명과학은 **`[12생과..]`**다. 진로·융합선택 접두어는 아래와 같다.

| 과목 | 접두어 | 과목 | 접두어 |

#### M01. 뜨거운 물과 찬물의 열평형
1. 중학교 / 과학 / (3) 열
2. **[9과03-01]** 온도와 열평형 과정을 물질을 구성하는 입자들의 배치나 움직임 등으로 설명할 수 있다. — 확인(정리본). 해설: "시간-온도 그래프 등을 활용하여 설명" — 연계: 직접
3. 실험: 뜨거운 물이 든 작은 컵을 찬물 비커에 넣고 두 온도 기록
4. 센서: DS18B20 2개 (안쪽 컵, 바깥 비커) / ⏱ 1 s, 5~10분
5. 그래프·해석: 가로 시간(s), 세로 온도(℃) 2선. 두 곡선이 점점 가까워져 같은 온도(열평형)에서 만난다. 처음에 온도 차가 클수록 기울기가 가파르다. 물의 양을 바꿔 평형 온도 위치를 비교한다 (질량이 큰 쪽에 가깝다).

#### M02. 열의 전달 3종 (전도·복사·단열)
1. 중학교 / 과학 / (3) 열
2. **[9과03-02]** 열은 전도, 대류, 복사로 전달됨을 알고, 열전달 과정을 모형 등을 사용하여 다양하게 표현할 수 있다. — 확인(정리본). 적용 시 고려 사항: "온도를 측정하거나 열의 전도를 관찰하는 활동에서 온도 센서 등 디지털 탐구 도구를 활용" — 연계: 직접
3. 실험: (가) 구리·알루미늄·철 막대 한쪽 끝을 뜨거운 물에 넣고 반대쪽 끝 온도 비교 (나) 검은 캔과 흰 캔을 전등 아래 두고 온도 상승 비교 (다) 단열재(스티로폼, 알루미늄 호일, 맨 컵)별 뜨거운 물 냉각 비교
4. 센서: DS18B20 2~3개 (+조도로 전등 세기 일정한지 확인) / ⏱ 1~5 s
5. 그래프·해석: 가로 시간, 세로 온도. (가) 열전도가 잘 되는 금속일수록 처음 기울기가 크다 (구리 > 알루미늄 > 철). (나) 검은 캔의 기울기와 최고 온도가 더 크다 (복사 흡수). (다) 냉각 기울기가 작을수록 단열이 잘 된다.

#### M03. 물과 식용유의 비열 비교
1. 중학교 / 과학 / (3) 열
2. **[9과03-03]** 물질에 따라 비열과 열팽창 정도가 다름을 알고, 이러한 성질이 일상생활에서 유용하게 활용됨을 인식할 수 있다. — 확인(정리본). 탐구 활동: "온도 센서를 이용하여 여러 가지 액체의 비열 비교하기" — 연계: 직접
3. 실험: 같은 질량의 물과 식용유를 같은 열원(물중탕 또는 같은 전열기)으로 가열
4. 센서: DS18B20 2개 / ⏱ 2 s, 5분
5. 그래프·해석: 가로 시간, 세로 온도. 둘 다 직선에 가깝게 오른다. 기울기는 1/비열에 비례하므로, 식용유의 기울기가 약 2배 크다 → 물의 비열이 더 크다. 기울기 비로 비열 비를 계산해 본다.

#### M04. 물과 에탄올의 증발 냉각
1. 중학교 / 과학 / (4) 물질의 상태 변화
2. **[9과04-01]** 확산 및 증발 현상을 관찰하여 물질을 구성하는 입자가 운동하고 있음을 추론할 수 있다. — 확인(정리본) — 연계: 응용
3. 실험: 온도 센서 끝에 거즈를 감고 물, 에탄올을 각각 적신 뒤 공기 중에 꺼내 둔다
4. 센서: DS18B20 2개 / ⏱ 1 s, 3~5분
5. 그래프·해석: 가로 시간, 세로 온도. 둘 다 실온보다 내려간다. 에탄올이 더 빨리, 더 많이 내려간다 → 증발이 빠를수록 열을 많이 빼앗는다. 다 마르면 실온으로 돌아온다. 선풍기 바람으로 바꿔 증발 속도를 비교할 수 있다.

#### M05. 얼음→물→끓음 가열 곡선
1. 중학교 / 과학 / (4) 물질의 상태 변화
2. **[9과04-03]** 여러 가지 물질의 상태 변화를 관찰하고, 이를 입자 모형으로 설명할 수 있다. / **[9과04-04]** 물질의 상태 변화와 열에너지 출입 관계를 이해하고, 이를 실생활에 적용하여 과학의 유용성을 인식할 수 있다. — 확인(정리본). 탐구 활동: "상태 변화 실험에서 가열 곡선 또는 냉각 곡선 그리기" — 연계: 직접
3. 실험: 잘게 부순 얼음을 비커에서 저으며 가열해 끓을 때까지 기록
4. 센서: DS18B20 (끓는 구간은 짧게) / ⏱ 2 s, 15~20분
5. 그래프·해석: 가로 시간, 세로 온도. 0 ℃ 근처 평탄 구간(녹는 동안), 기울기 구간(물 가열), 약 100 ℃ 평탄 구간(끓음). 평탄 구간에서 가한 열은 상태 변화에 쓰인다. 평탄 구간의 길이를 비교하면 기화열이 융해열보다 크다는 것을 볼 수 있다.

#### M06. 스테아르산 냉각 곡선 (응고할 때 열 방출)
1. 중학교 / 과학 / (4) 물질의 상태 변화
2. **[9과04-04]** (M05와 같음) — 확인(정리본) — 연계: 직접
3. 실험: 녹인 스테아르산(또는 팔미트산)이 든 시험관을 실온에서 식힌다
4. 센서: DS18B20 / ⏱ 2 s, 10~15분
5. 그래프·해석: 가로 시간, 세로 온도. 약 69 ℃(팔미트산은 약 63 ℃)에서 평탄 구간이 생긴다. 평탄 구간 = 어는점. 식는 동안에도 온도가 일정한 것은 응고하면서 열을 내놓기 때문이다.

#### M07. 용수철의 탄성력
1. 중학교 / 과학 / (5) 힘의 작용
2. **[9과05-02]** 중력, 탄성력, 마찰력, 부력을 이해하고, 각 힘의 특징을 크기와 방향으로 설명할 수 있다. — 확인(정리본). 탐구 활동: "용수철의 탄성력 측정하기" — 연계: 직접
3. 실험: 로드셀에 용수철을 걸고, 아래쪽 끝을 1 cm씩 당겨 고정할 때마다 힘을 기록
4. 센서: 로드셀 (g → N 환산) / ✍ 값 입력: 늘어난 길이(cm)
5. 그래프·해석: 가로 늘어난 길이, 세로 탄성력. 원점을 지나는 직선이고, 기울기 = 용수철 상수. 용수철 두 개를 직렬로 연결하면 기울기가 줄어든다. 너무 많이 늘리면 직선에서 벗어난다 (탄성 한계).

#### M08. 물속에서 부력 측정
1. 중학교 / 과학 / (5) 힘의 작용
2. **[9과05-02]** (M07과 같음) — 확인(정리본). 탐구 활동: "물속에서 부력 측정하기" — 연계: 직접
3. 실험: 로드셀에 추(원기둥)를 매달고 물에 조금씩 잠기게 한다. 변형: 정지 상태에서 나무도막을 끌어 마찰력 측정 (⏱)
4. 센서: 로드셀 / ✍ 잠긴 깊이(cm) 입력, 또는 ⏱ 천천히 잠기게 하며 기록
5. 그래프·해석: 가로 잠긴 깊이(또는 잠긴 부피), 세로 측정 무게. 잠긴 부피에 비례해 무게가 줄어들고, 다 잠기면 평탄해진다. 줄어든 무게 = 부력 = 밀어낸 물의 무게 (1 cm³당 약 0.0098 N). 마찰력 변형에서는 끄는 힘이 최고점(최대 정지 마찰력)을 찍은 뒤 조금 낮은 평탄 구간(운동 마찰력)으로 내려간다.

#### M09. 기체의 압력과 부피 (보일 법칙)
1. 중학교 / 과학 / (6) 기체의 성질
2. **[9과06-02]** 기체의 압력과 부피 관계를 실험 결과로부터 알아내고, 이를 입자 모형으로 해석할 수 있다. — 확인(정리본). 적용 시 고려 사항: "데이터를 수집하거나 시각화할 때 다양한 센서와 소프트웨어를 활용" — 연계: 직접
3. 실험: 기압 센서를 넣은 밀폐 용기에 주사기를 연결하고, 주사기를 밀거나 당긴다
4. 센서: 기압 / ✍ 전체 기체 부피(mL) 입력 (용기 + 관 + 주사기 부피를 더함)
5. 그래프·해석: 가로 부피, 세로 압력. 반비례 곡선이 나온다. 가로축을 1/V로 바꾸면 원점 근처를 지나는 직선이 되고, P×V가 거의 일정하다. 센서 범위(약 1100 hPa) 때문에 압축은 약 10 % 이내로 한다.

#### M10. 기체의 온도와 부피 (샤를 법칙)
1. 중학교 / 과학 / (6) 기체의 성질
2. **[9과06-03]** 기체의 온도와 부피 관계를 실험 결과로부터 알아내고, 이를 입자 모형으로 해석할 수 있다. — 확인(정리본) — 연계: 직접
3. 실험: 끝을 막은 주사기(또는 모세관에 물방울을 넣은 시험관)를 물중탕에 넣고 온도를 바꾸면서 부피 눈금을 읽는다
4. 센서: DS18B20 (중탕 온도 자동 기록) / ✍ 부피(mL) 입력
5. 그래프·해석: 가로 온도(℃), 세로 부피. 직선이다. 직선을 왼쪽으로 늘이면 약 −273 ℃에서 부피 0에 닿는다 (절대 영도 개념은 심화). 변형: 부피를 고정한 플라스크에 기압 센서를 넣으면 압력–온도 직선이 나온다.

#### M11. 끓는점·녹는점은 양과 관계없다
1. 중학교 / 과학 / (8) 물질의 특성
2. **[9과08-01]** 물질의 특성의 의미를 알고, 실험을 통해 밀도, 용해도, 녹는점, 끓는점 등을 설명할 수 있다. — 확인(정리본) — 연계: 직접
3. 실험: 에탄올 10 mL와 20 mL를 물중탕으로 가열한다 (또는 스테아르산 2 g과 4 g을 냉각한다)
4. 센서: DS18B20 2개 / ⏱ 2 s
5. 그래프·해석: 가로 시간, 세로 온도. 양이 많은 쪽은 평탄 구간에 늦게 도달하지만, 평탄 구간의 높이(약 78 ℃)는 같다 → 끓는점은 물질의 특성이다. 에탄올은 불이 붙으므로 직접 가열하지 않는다.

#### M12. 순물질과 혼합물 구별 (물 vs 소금물)
1. 중학교 / 과학 / (8) 물질의 특성
2. **[9과08-02]** 물질의 특성을 근거로 우리 주변의 물질을 순물질과 혼합물로 분류할 수 있다. — 확인(정리본) — 연계: 응용
3. 실험: 물과 소금물을 얼음+소금 한제에 넣어 얼린다 (앱의 어는점 템플릿 재사용 가능). 또는 둘 다 가열해 끓인다.
4. 센서: DS18B20 2개 / ⏱ 2 s
5. 그래프·해석: 가로 시간, 세로 온도. 순수한 물은 0 ℃에서 평탄 구간이 뚜렷하다. 소금물은 0 ℃보다 낮은 곳에서 얼기 시작하고, 어는 동안에도 온도가 계속 내려간다 (평탄하지 않음) → 혼합물. 끓일 때도 소금물은 100 ℃보다 높고 계속 오른다.

#### M13. 물–에탄올 혼합물 증류
1. 중학교 / 과학 / (8) 물질의 특성
2. **[9과08-03]** 물질의 특성을 이용하여 혼합물이 분리되는 원리를 이해하고, 이를 이용한 사례를 주변에서 찾을 수 있다. — 확인(정리본) — 연계: 응용
3. 실험: 물–에탄올 혼합물을 가지 달린 플라스크에서 가열하고, 증기 온도(가지 높이)를 기록
4. 센서: DS18B20 (가지관 높이에 둠) / ⏱ 2 s, 20분. 받은 액체 부피를 함께 적어 둔다
5. 그래프·해석: 가로 시간, 세로 증기 온도. 약 78~80 ℃ 근처에서 완만한 구간(에탄올이 주로 나옴)이 생긴 뒤, 100 ℃로 올라간다(물). 끓는점 차이로 분리된다는 것을 확인한다. 구간마다 받은 액체에 불을 붙여 보면 앞부분만 탄다 (교사 시연).

#### M14. 물체의 색과 빛의 합성
1. 중학교 / 과학 / (10) 빛과 파동
2. **[9과10-03]** 물체의 색을 빛의 반사와 관련지어 설명하고, 영상 장치에서 빛의 합성을 이용하여 다양한 색이 표현되는 원리를 이해할 수 있다. — 확인(정리본) — 연계: 응용
3. 실험: (가) 색종이 여러 장을 흰 빛 아래에서 RGB 측정 (나) 빨강 셀로판, 초록 셀로판을 겹쳐 통과한 빛 측정 (다) RGB LED의 R·G·B 밝기를 조절해 노랑·자홍·흰색 만들기
4. 센서: TCS34725 / 📊 시료별 단발 비교
5. 그래프·해석: R·G·B 막대그래프. 빨간 종이는 R만 크다 (빨간 빛만 반사). 노란 종이는 R과 G가 크다 → 노랑 = 빨강 + 초록. 셀로판을 겹치면 모든 채널이 작아진다 (빛이 흡수됨, 색의 혼합과 빛의 합성의 차이).

#### M15. 소리의 크기 (진폭)와 거리
1. 중학교 / 과학 / (10) 빛과 파동
2. **[9과10-04]** 파동의 발생과 전달 과정을 이해하고, 소리의 특성을 진폭, 진동수, 파형 등의 과학적 용어로 표현할 수 있다. — 확인(정리본). 탐구 활동: "디지털 탐구 도구를 이용하여 소리의 진폭, 진동수, 파형 탐구하기" — 연계: 직접
3. 실험: 스피커에서 일정한 소리를 내고 (가) 볼륨 단계 (나) 스피커와의 거리를 바꿀 때 소리 크기를 기록
4. 센서: 소리 크기(상대값) + 초음파 거리 / ✍ 볼륨 단계 또는 거리 입력
5. 그래프·해석: 가로 거리(또는 볼륨), 세로 소리 크기(상대). 거리가 멀어지면 줄어들고, 볼륨(진폭)이 커지면 커진다. **한계**: 이 센서로는 진동수와 파형을 볼 수 없으므로, 진동수는 스마트폰 앱이나 오실로스코프와 함께 쓴다.

#### M16. 빛의 세기에 따른 광합성 (CO2 감소)
1. 중학교 / 과학 / (12) 식물과 에너지
2. **[9과12-01]** 광합성 과정을 이해하고, 환경 요인과 광합성의 관계를 탐구하는 실험을 설계할 수 있다. — 확인(정리본). 적용 시 고려 사항: "광합성 실험은 디지털 탐구 도구를 이용하여 데이터를 얻고 … 디지털 기반 탐구 활동" — 연계: 직접
3. 실험: 밀폐 용기(투명 통)에 잎이 많은 화분이나 시금치 잎을 넣고 LED 거리(또는 밝기)를 바꾼다. 같은 통을 빛 → 어둠 순서로 둔다.
4. 센서: SCD40 CO2 + 조도 + (온도) / ⏱ 10 s, 조건마다 10~15분
5. 그래프·해석: 가로 시간, 세로 CO2(ppm). 빛이 있으면 CO2가 줄고, 어두우면 늘어난다. 조건마다 기울기(ppm/분)를 구해 '조도–광합성 속도' 그래프를 다시 그리면, 빛이 셀수록 빨라지다가 포화된다. 전등 열 때문에 온도가 오르지 않는지 온도도 함께 본다.

#### M17. 식물과 발아 종자의 호흡
1. 중학교 / 과학 / (12) 식물과 에너지
2. **[9과12-02]** 식물의 호흡과 광합성의 관계를 이해하고, 호흡과 광합성 과정에서 출입하는 에너지와 물질의 변화를 분석할 수 있다. — 확인(정리본) — 연계: 응용
3. 실험: 물에 불린 콩(발아 종자)과 삶은 콩을 각각 밀폐 용기(또는 보온병)에 넣는다
4. 센서: CO2 + DS18B20 / ⏱ 30 s, 1~수 시간
5. 그래프·해석: 가로 시간, 세로 CO2와 온도. 발아 종자 쪽은 CO2가 꾸준히 늘고 온도도 조금 오른다 (호흡으로 에너지 방출). 삶은 콩은 거의 변하지 않는다 (대조군). M16의 어둠 구간 기울기와 비교하면 광합성과 호흡의 관계가 보인다.

#### M18. 운동 전후 날숨의 CO2
1. 중학교 / 과학 / (13) 동물과 에너지
2. **[9과13-05]** 동물이 세포호흡을 통해 에너지를 얻는 과정을 소화, 순환, 호흡, 배설과 관련지어 통합적으로 설명할 수 있다. — 확인(정리본) — 연계: 응용
3. 실험: 큰 비닐봉지(또는 5 L 통)에 날숨을 한 번 불어 넣고 측정한다. 제자리뛰기 1분 뒤 다시 측정한다.
4. 센서: CO2 (+온습도) / ⏱ 5 s, 조건마다 2분
5. 그래프·해석: 가로 시간, 세로 CO2. 날숨은 실내 공기보다 훨씬 높고, 운동 후에 더 높다 → 세포호흡이 늘었다. **주의**: SCD40은 2000 ppm 넘게 진한 기체에서 정확도가 떨어지므로, 같은 양의 날숨을 같은 큰 통에 넣어 희석하고 상대 비교만 한다. 위생을 위해 개인 빨대를 쓴다.

#### M19. 전압–전류–저항 관계 (옴의 법칙)
1. 중학교 / 과학 / (14) 전기와 자기
2. **[9과14-02]** 전기 회로에서 전류를 모형으로 설명하고, 실험을 통해 저항, 전류, 전압 사이의 관계를 이끌어낼 수 있다. — 확인(정리본). 적용 시 고려 사항: "전기 회로 실험에서 디지털 탐구 도구나 가상 실험을 활용" — 연계: 직접
3. 실험: 건전지 1~3개(또는 가변저항 분압)에 '측정 저항 R + 기준저항 100 Ω'을 직렬로 연결한다. 두 저항 양단의 전압을 잰다. 변형: 직렬·병렬 연결에서 각 저항의 전압을 비교한다 (**[9과14-03]**).
4. 센서: 전압 2채널 / ✍ 전원 단계(전지 개수) 입력
5. 그래프·해석: 전류 I = (기준저항 전압)/100 Ω. 가로 전류, 세로 R 양단 전압. 원점을 지나는 직선이고, 기울기 = 저항. 저항을 바꾸면 기울기가 달라진다. 0~5 V 안에서만 측정한다.

#### M20. 광원과의 거리에 따른 밝기
1. 중학교 / 과학 / (15) 별과 우주
2. **[9과15-01]** 연주시차를 이용하여 별까지의 거리를 구할 수 있고, 별의 등급과 밝기의 관계 및 표면 온도와 색의 관계를 설명할 수 있다. — 확인(정리본). 탐구 활동(정리본 기준): "디지털 탐구 도구를 활용하여 광원으로부터의 거리에 따른 빛의 세기 실험하기" — 연계: 직접
3. 실험: 어두운 방에서 작은 전구(점광원)로부터 조도 센서를 10 cm씩 멀리 옮긴다
4. 센서: 조도 + 초음파 거리 (또는 ✍ 거리 입력)
5. 그래프·해석: 가로 거리, 세로 조도. 거리가 2배가 되면 밝기는 약 1/4이 된다. 가로축을 1/r²로 바꾸면 직선이 된다 → 같은 밝기의 별이라도 멀수록 어둡게 보인다 (등급과 거리). 변형: 전구 전압을 바꾸며 RGB 비(R/B)를 재면 '온도와 색'으로 연결할 수 있다 (12지구03-02 참고).

#### M21. 화학 반응에서 질량 보존
1. 중학교 / 과학 / (16) 화학 반응의 규칙성
2. **[9과16-03]** 화학 반응에서 질량이 보존됨을 실험을 통해 추론할 수 있다. — 확인(정리본). 탐구 활동: "화학 반응 전후의 질량 변화 관찰하기" — 연계: 직접
3. 실험: 페트병 안에 식초와 베이킹소다(작은 컵에 따로)를 넣고 마개를 닫은 채 로드셀 위에서 섞는다. 다음에는 마개를 연 채로 반복한다. 변형: 강철솜 연소(질량 증가).
4. 센서: 로드셀 / ⏱ 1 s, 3분
5. 그래프·해석: 가로 시간, 세로 질량(g). 닫은 경우는 평탄 (보존). 연 경우는 기체가 빠져나가 감소하다가 평탄해진다. 감소량 = 빠져나간 CO2 질량. 마개를 다시 열면 그때 줄어드는 것으로 확인할 수 있다.

#### M22. 발열 반응과 흡열 반응
1. 중학교 / 과학 / (16) 화학 반응의 규칙성
2. **[9과16-06]** 화학 반응에서 열에너지가 출입함을 알고, 생활 속 사례를 조사하여 발표할 수 있다. — 확인(정리본). 탐구 활동: "화학 반응을 이용한 간단한 냉각 장치 만들기" — 연계: 직접
3. 실험: (가) 철가루 + 소금물 + 활성탄 (손난로) (나) 구연산 + 베이킹소다 + 물 (냉각) (다) 염화칼슘 용해(발열), 질산암모늄 용해(흡열)
4. 센서: DS18B20 / ⏱ 2 s, 5~10분
5. 그래프·해석: 가로 시간, 세로 온도. 발열은 위로 올라갔다가 천천히 식고, 흡열은 아래로 내려갔다가 실온으로 돌아온다. 최고(최저) 온도 변화량 ΔT로 재료의 양을 비교해 '가장 좋은 냉각팩'을 설계한다.

#### M23. 페트병 구름 생성 (단열 팽창)
1. 중학교 / 과학 / (17) 날씨와 기후변화
2. **[9과17-03]** 상대습도, 단열 팽창 및 응결 현상의 관계를 이해하고, 구름의 생성과 강수 과정을 설명할 수 있다. — 확인(정리본). 탐구 활동: "디지털 탐구 도구를 이용하여 구름 생성 과정 실험하기" — 연계: 직접
3. 실험: 물을 조금 넣고 향 연기를 넣은 페트병에 센서를 넣는다. 펌프 마개로 압축한 뒤 한 번에 연다.
4. 센서: 기압 + 온도 + 습도 (BME280 한 개로 가능) / ⏱ 0.2~1 s
5. 그래프·해석: 가로 시간, 세로 기압·온도 (축 2개). 압축하면 기압과 온도가 오르고, 열면 기압이 뚝 떨어지면서 온도도 내려가고 뿌옇게 구름이 생긴다. 온도가 이슬점 아래로 내려가면 응결한다. 연기(응결핵)가 없을 때와 비교한다.

#### M24. 기압 연속 관측과 날씨
1. 중학교 / 과학 / (17) 날씨와 기후변화
2. **[9과17-04]** 기압, 기단, 전선의 개념을 이해하고, 일기도에서 저기압과 고기압의 분포에 따른 날씨를 해석할 수 있다. — 확인(정리본) — 연계: 응용
3. 실험: 교실 창가에서 기압과 온습도를 3~7일 기록하고 일기도와 비교한다. 변형: 계단 1층부터 옥상까지 층마다 기압을 잰다 (✍ 층수).
4. 센서: 기압 + 온습도 / ⏱ 5~10분 간격 (장시간)
5. 그래프·해석: 가로 날짜·시간, 세로 기압(hPa)과 습도. 저기압이 다가오면 기압이 내려가고 습도가 오르며 흐리거나 비가 온다. 고기압이면 기압이 높고 맑다. 층별 변형에서는 높이가 올라갈수록 약 0.12 hPa/m씩 기압이 낮아진다.

#### M25. 운동 그래프 (걷기, 경사면 수레)
1. 중학교 / 과학 / (19) 운동과 에너지
2. **[9과19-01]** 직선상에서 움직이는 물체의 운동을 그래프로 나타내고 해석할 수 있다. / **[9과19-02]** 자유 낙하하는 물체의 운동에서 시간에 따른 속력의 변화가 일정함을 분석할 수 있다. — 확인(정리본). 해설: "속력이 변하는 경우에는 시간-속력 그래프를 그려서 운동을 분석" — 연계: 직접(19-01) / 응용(19-02)
3. 실험: (가) 초음파 센서 앞에서 학생이 일정하게 걷기, 멈추기, 점점 빠르게 걷기 (그래프 맞추기 게임) (나) 경사면에서 수레를 굴리고 위쪽에서 거리 측정
4. 센서: 초음파 거리 / ⏱ 20~25 Hz
5. 그래프·해석: 가로 시간, 세로 거리 → 앱에서 속력(기울기)을 계산한다. 등속이면 거리–시간이 직선이고, 속력–시간은 수평이다. 경사면에서는 거리–시간이 포물선이고 속력–시간은 직선이며, 이 기울기가 가속도다. 경사각을 키우면 기울기가 커지고 수직(자유낙하)에 가까워진다. 실제 자유낙하는 시간이 짧아 점이 적으므로 경사면으로 대신한다.

#### H01. 진자의 주기와 길이 측정
1. 고1 / 통합과학1 / (1) 과학의 기초
2. **[10통과1-01-01]** 자연을 시간과 공간에서 기술할 수 있음을 알고, 길이와 시간 측정의 현대적 방법과 다양한 규모의 측정 사례를 조사할 수 있다. / **[10통과1-01-02]** 과학 탐구에서 중요한 기본량의 의미를 알고, 자연 현상을 기술하는 데 단위가 가지는 의미와 적용사례를 설명할 수 있다. — 확인(교육청·정리본). 탐구 활동: "스마트 기기를 활용하여 여러 가지 기본량을 측정하고 분석하기" — 연계: 직접
3. 실험: 진자 추 옆(진동 방향)에 초음파 센서를 두고 거리를 기록한다. 줄 길이를 바꿔 반복한다.
4. 센서: 초음파 거리 / ⏱ 20 Hz, 20 s
5. 그래프·해석: 가로 시간, 세로 거리 → 사인 모양이다. 봉우리 사이 간격 = 주기 T. 길이 L을 바꿔 'L–T²' 그래프를 그리면 직선이다 (T = 2π√(L/g)). 기울기로 g를 구하고, 스톱워치로 잰 값과 정밀도를 비교한다.

#### H02. 온도 센서 보정과 반복 측정
1. 고1 / 통합과학1 / (1) 과학의 기초
2. **[10통과1-01-03]** 과학 탐구에서 측정과 어림의 의미를 알고, 일상생활의 여러 가지 상황에서 측정 표준의 유용성과 필요성을 논증할 수 있다. — 확인(교육청·정리본) — 연계: 응용
3. 실험: 센서 여러 개를 얼음물(0 ℃)과 끓는 물(약 100 ℃, 기압 보정)에 함께 넣어 비교한다. 같은 물을 10번 측정한다.
4. 센서: DS18B20 여러 개 / ⏱ 1 s + 📊
5. 그래프·해석: 센서별 막대그래프와 오차 막대. 센서마다 0.1~0.5 ℃ 정도 차이가 난다 → 기준점 두 개로 2점 보정을 한다. 평균, 표준편차, 유효숫자를 구한다. '측정 표준이 없으면 반마다 결과가 다르다'는 논증에 쓸 수 있다.

#### H03. 아날로그 신호를 디지털로
1. 고1 / 통합과학1 / (1) 과학의 기초
2. **[10통과1-01-04]** 자연에서 일어나는 다양한 변화를 측정⋅분석하여 정보를 산출함을 알고, 이러한 정보를 디지털로 변환하는 기술을 정보 통신에 활용하여 현대 문명에 미친 영향을 인식한다. — 확인(교육청·정리본). 해설: "센서를 통해 아날로그 형태의 다양한 신호가 전기 신호로 바뀌어 디지털 정보가 됨을 소개" — 연계: 직접
3. 실험: 가변저항을 천천히 돌리면서 '전압 → ADC 값'을 기록한다. 분해능(10비트/14비트)을 바꾸어 비교한다. 조도 센서 앞에서 손을 흔들어 샘플링 간격(1 Hz vs 20 Hz)에 따른 차이를 본다.
4. 센서: 가변저항(아날로그 입력), 조도 / ⏱ 간격 바꿔 가며
5. 그래프·해석: 가로 시간, 세로 ADC 값. 확대하면 계단 모양이 보인다 (양자화). 10비트는 5 V/1024 ≈ 4.9 mV 단위다. 샘플링이 느리면 빠른 변화를 놓친다. 디지털화의 한계와 정보 통신과의 연결을 토의한다.

#### H04. 결합 종류와 전기 전도성
1. 고1 / 통합과학1 / (2) 물질과 규칙성
2. **[10통과1-02-04]** 인류의 생존에 필수적인 물, 산소, 소금 등이 만들어지는 결합의 차이를 이해하고 각 물질의 성질과 관련지어 설명할 수 있다. — 확인(교육청·정리본). 해설: "각 화학 결합으로 나타나는 성질은 전기 전도성에 한정하여 다룬다" — 연계: 직접
3. 실험: 증류수, 수돗물, 설탕물, 에탄올 수용액, 소금물, 고체 소금(전극을 접촉)의 전기 전도도를 비교한다
4. 센서: EC / 📊 단발 비교
5. 그래프·해석: 시료별 막대그래프 (μS/cm, 로그 축 권장). 소금물만 매우 크다 → 이온 결합 물질은 수용액에서 이온이 움직여 전류가 흐른다. 고체 소금과 설탕물은 거의 0이다 (고체에서는 이온이 고정, 공유 결합 분자는 이온이 없음).

#### H05. 반도체 소자의 특성 (서미스터, 광센서)
1. 고1 / 통합과학1 / (2) 물질과 규칙성
2. **[10통과1-02-06]** 지구를 구성하는 물질을 전기적 성질에 따라 구분할 수 있고, 물질의 전기적 성질을 응용하여 일상생활과 첨단기술에서 다양한 소재로 활용됨을 인식한다. — 확인(교육청·정리본) — 연계: 응용
3. 실험: 서미스터와 고정저항 분압 회로를 따뜻한 물에 넣어 식히면서 전압과 온도를 함께 기록한다. LDR(광저항) 분압 회로를 조도와 함께 기록한다.
4. 센서: 전압 + DS18B20 (+조도) / ⏱ 2 s
5. 그래프·해석: 가로 온도, 세로 서미스터 저항(분압으로 계산). 온도가 오르면 저항이 크게 줄어든다 (NTC 반도체, 금속 도선과 반대). LDR은 밝을수록 저항이 줄어든다. 이 성질을 이용해 센서를 만든다는 것을 정리한다.

#### H06. 모래와 물의 가열·냉각 (해륙풍 모형)
1. 고1 / 통합과학1 / (3) 시스템과 상호작용
2. **[10통과1-03-01]** 지구 시스템은 태양계라는 시스템의 구성요소임을 알고, 지구 시스템을 구성하는 권역들 간의 물질 순환과 에너지 흐름의 결과로 나타나는 현상을 논증할 수 있다. — 확인(교육청·정리본) — 연계: 응용
3. 실험: 같은 그릇에 모래와 물을 담고 전등을 10분 켰다가 끈다. 각 표면 바로 아래 온도를 잰다.
4. 센서: DS18B20 2개 + 조도 / ⏱ 5 s, 20분
5. 그래프·해석: 가로 시간, 세로 온도 2선. 모래가 빨리 데워지고 빨리 식는다 (비열 차이). 낮에는 육지가 더 따뜻하고 밤에는 바다가 더 따뜻하다 → 해풍과 육풍의 방향. 향 연기로 대류 방향을 함께 보면 좋다.

#### H07. 경사면·낙하 운동 분석
1. 고1 / 통합과학1 / (3) 시스템과 상호작용
2. **[10통과1-03-03]** 중력의 작용으로 인한 지구 표면과 지구 주위의 다양한 운동을 설명할 수 있다. — 확인(교육청·정리본). 탐구 활동: "자유 낙하와 수평으로 던진 물체의 운동을 시각화하여 비교하기" — 연계: 응용 (센서는 연직 방향만 측정)
3. 실험: 경사각을 바꿔 가며 수레를 굴린다. 가벼운 커피 필터를 초음파 센서 아래로 떨어뜨린다 (공기 저항, 종단 속도). 과탐1의 '갈릴레이 경사면 실험 재현'(10과탐1-01-01)과 겸할 수 있다.

| CE3 | **[12기환02-02]** 빙상의 융해와 열팽창으로 인한 해수면 상승을 기후변화와 연계하여 설명할 수 있다. — 확인(정리본) / 응용 | (가) 육지 얼음 vs 바다 얼음 녹이기 수위 (나) 물을 데울 때 가는 관의 수위 상승 | 온도 ⏱ + 수위 ✍ 입력 | 바다 얼음(물에 뜬 얼음)은 수위 변화가 거의 없고, 육지 얼음은 수위를 올린다. '온도–수위' 직선 → 열팽창 기여 |
| CE4 | **[12기환02-07]** 수생태계의 물꽃 현상을 이해하고, 기후변화가 수생태계의 생물다양성에 끼치는 영향을 추론할 수 있다. — 확인(정리본) / 응용 | 영양염(비료)·수온을 다르게 한 연못물의 조류 증식 | 색 센서(초록·탁도) + DO + 온도 ⏱ 1시간, 1~2주 | 따뜻하고 영양염이 많은 쪽에서 초록 흡광도가 빨리 늘어난다. DO는 낮과 밤의 차이가 커진다 (밤에 산소 부족) |
| CE5 | **[12기환03-01]** 산호의 멸종으로 인한 백화현상의 예를 통해 기후변화가 해양생태계에 미치는 영향을 살펴보고, 바다 사막화를 예방하거나 복원할 수 있는 과학기술의 사례를 제시할 수 있다. — 확인(정리본) / 응용 | 해양 산성화: CO2를 녹인 물(pH 단계별)에 조개껍데기를 담가 질량 감소 | pH ✍ + 로드셀/저울 ✍ 날짜 | pH가 낮을수록 탄산칼슘 껍데기 질량이 빨리 줄어든다 → 산호 골격 약화 |
| CE6 | **[12기환03-03]** 탄소중립 사회를 이루기 위한 탄소 저감 관련 과학기술 개발 현황을 알아보고, 이의 적용 사례를 제시할 수 있다. — 확인(정리본) / 응용 | 밀폐 상자에서 CO2 흡수 비교: 수산화칼슘, 활성탄, 화분(빛), 빈 상자 | CO2 ⏱ 30 s | 처음 CO2를 같게 맞춘 뒤 감소 기울기를 비교한다. 화학 흡수 > 식물 > 대조군 (조건에 따라 다름). 탄소 포집 기술과 연결 |

### 5-3. 융합과학 탐구 (4개, 12융탐)

이 과목은 '데이터 수집–평가–시각화–통계'가 성취기준 자체다. 위의 실험 아무거나를 프로젝트로 확장해 쓰면 된다.

| ID | 코드 | 활동 | 센서·방식 | 해석 포인트 |
|---|---|---|---|---|
| CS1 | **[12융탐02-01]** 실생활에서 관찰이나 경험을 통해 직접 얻은 데이터나 공개된 데이터를 가공하여 융합적 탐구 문제를 스스로 발견할 수 있다. — 확인(정리본) / 직접 | 교실 CO2·온습도 로그 + 학생 졸음 설문 → 문제 찾기 | CO2, 온습도 ⏱ | 센서 데이터와 사회적 데이터(설문)를 겹쳐 상관관계를 찾는다. 상관과 인과를 구분한다 |
| CS2 | **[12융탐02-03]** 디지털 탐구 도구를 포함한 다양한 도구를 활용하여 데이터를 수집하고, 수집한 데이터의 타당성과 신뢰성을 평가할 수 있다. — 확인(정리본) / 직접 | 같은 양을 센서 2종으로 측정 (DS18B20 vs 열전대, SCD40 vs 기상청 값) + 보정 | 온도 2종 등 ⏱ | 두 센서의 차이(편향)와 흩어짐(정밀도). 보정 전후 비교, 반복성 |
| CS3 | **[12융탐02-04]** 융합적 탐구 과정을 통해 얻은 데이터를 탐구 목적이나 맥락에 맞게 시각 자료로 표현할 수 있다. / **[12융탐02-05]** 평균, 표준편차 등을 바탕으로 데이터의 특성을 파악하고, 이를 토대로 가설이나 모형을 평가할 수 있다. — 확인(정리본) / 직접 | 반 전체가 같은 실험(예: H14 중화열)을 해서 데이터를 모으고 분석 | 실험에 따라 | 모둠별 결과의 평균 ± 표준편차, 이상치 판단, 오차 막대 그래프. 가설(중화점 20 mL)을 평가한다 |
| CS4 | **[12융탐01-04]** 인공지능을 포함한 디지털 탐구 도구나 기술의 활용 사례를 조사하고, 과학적 탐구 과정에서 디지털 탐구 도구와 기술 활용의 의의를 평가할 수 있다. — 확인(정리본) / 직접 | 같은 실험을 '수작업(온도계·스톱워치)'과 '센서 자동 기록'으로 해서 비교 | 온도 등 ⏱ | 데이터 수, 시간 해상도, 사람 오차. 디지털 도구의 장점과 한계(보정, 고장, 과신)를 평가한다 |
