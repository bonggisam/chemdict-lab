ChemDict Lab 지원

아두이노 센서나 이 기기 센서로 과학 실험 데이터를 얻고 해석하는 무료 앱입니다 (아이폰·아이패드·맥·웹).

준비물

  • 아이폰·아이패드: 블루투스 보드 UNO R4 WiFi 또는 UNO Q
  • 맥: 위 블루투스 보드 + USB 보드(UNO R3·Nano·Mega·Leonardo·UNO R4, 호환 보드 포함)
  • 보드에 ChemDict 측정 프로그램을 한 번 올립니다 → 웹앱의 [측정 프로그램 설치] (UNO R3·Nano·Mega·Leonardo) 또는 Arduino IDE (UNO R4 WiFi·UNO Q)
  • 보드가 없으면 앱의 [이 기기로 바로 재기]로 소리·카메라 색·움직임을 실제로 재거나, [보드 없이 체험]으로 모든 기능을 써 볼 수 있습니다.

자주 묻는 것

  • 보드가 안 보여요 — 블루투스 권한을 허용했는지, 다른 기기가 이미 연결하지 않았는지, UNO Q라면 켠 뒤 1분 기다렸는지 확인합니다.
  • 센서를 못 찾아요 — 앱의 연결 그림대로 다시 꽂고 [센서 다시 찾기]를 누릅니다. 연결 사진 점검 목록을 이용하세요.
  • 값이 이상해요 — 측정 화면의 [센서 점검]에서 얼음물·완충액 같은 기준과 비교해 오차를 확인하고 [보정]합니다.
  • 측정하다가 화면이 꺼져요 — 웹앱(크롬·엣지)과 애플 앱 2.1부터는 측정 중에 화면이 저절로 꺼지지 않습니다. 애플 앱에서 블루투스 보드는 화면을 잠가도 계속 기록하고, 이 기기 센서는 화면을 켜 둔 동안만 기록합니다.
  • 긴 실험(몇 시간·며칠)은요 — 측정 화면의 [끝내기]에서 시간을 정하면 그때 멈추고 알려 줍니다. 기기는 전원에 꽂아 두세요.
