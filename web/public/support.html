ChemDict Lab 지원

아두이노 센서로 과학 실험 데이터를 얻고 해석하는 무료 앱입니다 (아이패드·맥·웹).

준비물

  • 아이패드: 블루투스 보드 UNO R4 WiFi 또는 UNO Q
  • 맥: 위 블루투스 보드 + USB 보드(UNO R3·Nano·Mega·Leonardo·UNO R4, 호환 보드 포함)
  • 보드에 ChemDict 측정 프로그램을 한 번 올립니다 → 웹앱의 [측정 프로그램 설치] (UNO R3·Nano·Mega·Leonardo) 또는 Arduino IDE (UNO R4 WiFi·UNO Q)
  • 보드가 없으면 앱의 [보드 없이 체험]으로 모든 기능을 써 볼 수 있습니다.

자주 묻는 것

  • 보드가 안 보여요 — 블루투스 권한을 허용했는지, 다른 기기가 이미 연결하지 않았는지, UNO Q라면 켠 뒤 1분 기다렸는지 확인합니다.
  • 센서를 못 찾아요 — 앱의 연결 그림대로 다시 꽂고 [센서 다시 찾기]를 누릅니다. 연결 사진 점검 목록을 이용하세요.
  • 값이 이상해요 — 측정 화면의 [센서 점검]에서 얼음물·완충액 같은 기준과 비교해 오차를 확인하고 [보정]합니다.
